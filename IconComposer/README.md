# Marks Icon Composer artwork

The `Layers` folder contains 1024 × 1024 SVG artwork named in back-to-front order for Icon Composer.

## Import

1. Open Icon Composer and create a document named `AppIcon` for macOS.
2. Keep the canvas clear with no custom background artwork or gradient.
3. Drag the `Layers` folder into the sidebar. Keep the numbered order from back to front.
4. Put each imported SVG in its own group: Notebook Cover and Paper and Markdown.
5. Use Combined material for each group so the internal shading reads as one physical object.
6. Add depth shadows, specular highlights, refraction, and appearance variants in Icon Composer. Use a subtle shadow for the Cover and a medium shadow for the Paper.
7. Save the result as `AppIcon.icon` and add it to the Xcode project.

`Marks-preview.svg` is a flattened design reference only. Don’t import it as an Icon Composer layer.
